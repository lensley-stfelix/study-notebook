# Study Notebook

An offline Python desktop application for organizing computer science coursework, notes, diagrams, screenshots and locally stored videos.

## Features

- Import Markdown and text lessons in natural numerical order.
- Paste screenshots and attach local images and videos.
- View lessons in an offline HTML preview.
- Reorder lessons and restore their course sequence from original files.
- Delete lessons with recoverable local storage.

## Technology

Python, Tkinter, Pillow, JSON, HTML and Markdown. The companion transcript exporter uses Beautiful Soup and Playwright.

## Project status

The application has been built and tested locally. Source files and installation instructions are pending upload. Personal notes, media, browser profiles and exported coursework will not be published.
